# Bundled Hearthstone artwork

Generated by `tools/fetch_art.py` (Python with Pillow). Artwork is converted to
local, uncompressed RGB/RGBA TGA textures with power-of-two dimensions for WoW.
The game never makes HTTP requests. `art-report.json` records every source URL,
source-byte SHA-256, output size, and download failure.

- Illustrations: https://hearthstonejson.com/docs/images.html
- Empty card frames, card back, hero/power frames and mana: https://github.com/HearthSim/Joust/tree/main/assets/images
- Board: https://github.com/Rymedy/hearthstone-web/blob/master/src/images/board3.jpg
- Rarity gems in their frame sockets (`rarity-<type>-<rarity>.tga`): https://github.com/HearthSim/sunwell/tree/master/assets
  (MIT, `rarity-gems-LICENSE.txt`; hashes in `rarity-gems-report.json`; `tools/import_rarity_gems.py`)
- End Turn (`turn-button.tga`, `turn-button-enemy.tga`): the real button lifted from `board.tga`,
  lettering inpainted (`tools/build_turn_button.py`, docs/16)
- Victory / defeat (`result-ornament.tga`, `result-frame.tga`, `result-plaque.tga`, `mask-result-arch.tga`):
  keyed from the Hearthstone wiki's "Play mode victory" screenshot (`tools/build_result_art.py`;
  source URL and hash in `result-art.json`)
- Open Packs room (`pack-room.tga`): Rymedy's `openpacksbackground.png` with its Shop button removed
  (`tools/build_pack_room.py`)
- Taunt glow (`inplay_minion_taunt-glow.tga`): traced from the Joust taunt shield (`tools/build_taunt_glow.py`)
- The three match boards are composited and then polished by `tools/composite_boards.py`,
  `tools/repair_board_corners.py` and `tools/polish_boards.py` (docs/14)

The illustrations cover every collectible card in the pinned database.
Four noncollectible records are unavailable from the illustration service:
`XXX_040`, `XXX_039`, `PlaceholderCard`, and `skele11`; these retain generic
fallback art. The board is a Hearthstone board, not the original classic board.
Card text, cost and stats remain those in the pinned database, not text from
modern rendered cards. This pack does not contain Hearthstone audio.
